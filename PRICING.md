# Pricing (not chosen)

This is **not** a price list. A human must decide whether AgentDeck is free
open-source, a paid companion, a seat, usage-billed, or something else.

## What is already true (do not invent numbers)

- Users pay their **own** model and CLI vendors (Anthropic, OpenAI, Cursor, xAI, Google, Perplexity, …).
- AgentDeck’s token ledger records tokens and, when the official catalog has a row, integer micro-USD. Unpriced stays `NULL`. See [docs/METERING.md](docs/METERING.md).
- There is no AgentDeck cloud invoice. Hosted cells are specified, not billed.

## Human decision

Fill this section when you choose:

- License (see `LICENSE`)
- Companion: free / paid / donation
- Hosted cell: seat / usage / both
- Whether Homebrew and GitHub Releases are free downloads

Until then, do not print a dollar figure for AgentDeck itself anywhere in the product.
